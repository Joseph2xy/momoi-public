# Public source snapshot

## Publication and verification state

This repository is a clean source snapshot of Momoi, a working community voting and automatic VOD playback application. It excludes the private operational repository's history and user-specific authentication and voting notes.

The community instance is actively used. This source release is not a turnkey installation: deployment configuration, Twitch credentials and a separate Convex backend are required. Self-hosting instructions and further cleanup are still being improved.

See [README](../README.md), [configuration](operations.md#configuration) and [architecture](architecture.md). Existing documented checks are historical evidence, not a fresh verification of this snapshot or an independent installation.
